# 我感兴趣的（高优先级）

## AI / 技术
- 大模型架构突破、新训练方法、新模型发布（开源/闭源都看）
- AI Agent、Coding Agent 实际进展（非营销稿）
- Anthropic / OpenAI / Google DeepMind / Meta AI 官方动态
- 重要的 AI 安全 / 对齐研究
- 实战性强的工程文章（推理优化、长上下文、RAG 工程）

## 经济 / 金融
- 宏观：通胀、利率、汇率、人口、产业政策
- 中日经济关联、日本就业市场、跨境税收/保险话题
- NBER / 顶刊新发表的实证经济学论文
- 量化策略、ETF 资产配置层面的研究

# 我不感兴趣的（直接过滤）
- AI 公司融资估值的纯财经新闻（除非 >$10B 或战略性合作）
- 名人八卦、政治立场口水
- 已经被覆盖过的旧事件（重复信息）
- "10 Best Tools for X" 这类列表 SEO 内容
- 没有数据/链接支撑的纯观点贴

# 评分标准（Claude 用）
- 5: 改变我对某事看法的硬核新信息
- 4: 与我兴趣高度相关，值得读完
- 3: 相关但可以扫一眼标题就过
- 2: 边缘相关，可以放进"其它"
- 1: 完全不在范围内，扔掉
